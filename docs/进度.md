### 后端完成内容

**工程骨架（对应开发顺序 1~2）**

- `com.learn` 包结构：config / controller(9 前台 + 3 admin) / service+impl / mapper / entity(10) / vo(19) / dto(18) / exception / checker / common / util
- 全局配置：Sa-Token 拦截器、MyBatis-Plus 分页 + 逻辑删除 + 自动填充、CORS、全局异常处理、统一返回体 `Result<T>`、分页 `PageResult<T>`
- `sql/init.sql`：9 张表 + 索引齐全；`DataInitializer` 启动时幂等灌入种子数据（admin/admin123，5 个一级分类 + 6 个子分类 + 21 道题，覆盖四种题型、含 VIP 题）

**认证与安全（3~4）**

- 注册/登录/退出/找回密码；BCrypt 密码加密（spring-security-crypto）
- 渐进式图形验证码：注册/找回强制，登录失败 ≥3 次返回 `requireCaptcha=true`，≥5 次锁 15 分钟；验证码一次性销毁（无论成败）
- 邮箱验证码：6 位 TTL 10 分钟、60 秒冷却、IP 每日 10 次；登录失败提示统一（无账号枚举）；IP 15 分钟 20 次锁定
- 账号状态校验：每次请求查库，`status=0` 或已软删 → 强制登出并 401
- `QuestionAccessChecker` 统一 VIP 鉴权，覆盖文档 4.1 矩阵全部 11 个入口，越权条目题干脱敏
- 答案字段分级：`QuestionPracticeVO` 无 answer/answerText/analysis，SQL 层不查这三列

**刷题核心（5~8）**

- 刷题会话：sessionId + 有序 id 列表存缓存 TTL 2 小时，顺序/随机模式，解决翻页重复问题
- 判分：单选相等、多选排序归一化、判断 A/B、简答不判分（is_correct=NULL）
- 状态表 `INSERT ... ON DUPLICATE KEY UPDATE` 原子 upsert，计数在 SQL 内基于旧值累加
- 遗忘曲线：答错归零 +1 天，答对按 1/2/4/7/15 天顺延；连续答对 3 次或层级到 5 → mastered
- 错题本/复习队列查询条件与文档 4.3 逐字一致（复习队列双保险：mastered=0 且 next_review_time 非空）
- 统计：总答题数、正确率（流水表口径）、按分类正确率、连续打卡天数、错题本/复习队列条数

**互动与 VIP（9~10）**

- 收藏 toggle（软删翻转复用同一行）、笔记 upsert（`ON DUPLICATE KEY UPDATE`）+ 笔记列表分页
- 点赞五步事务：占位 upsert → `SELECT ... FOR UPDATE` 当前读 → 推导 delta → 更新状态 → `like_count` 原子增减（禁止负数）
- VIP 月/季/年卡 + 模拟支付，权益按剩余时长顺延发放；管理员手动设置直接覆盖

**管理后台（11~12）**

- 用户管理（禁用/启用强制登出、手动设 VIP、软删时改写 `__del_{id}` 释放唯一字段）
- 分类 CRUD（删除前三重校验：子分类、启用题目）
- 题目 CRUD + 上下架；EasyExcel 导入（PK 文件头校验、流式 500 条/批、批内 Set 查重、`分类+题干MD5` 查重、SKIP/OVERWRITE/ERROR 三策略、单批独立事务失败整批回滚、行级错误明细）、模板下载、按条件导出
- 数据统计 + `recalc-like` 点赞数兜底重算
