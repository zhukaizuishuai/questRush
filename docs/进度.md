## 2026-09-27 第三轮迭代：后台侧边栏选中态修复（AdminLayout）

### 问题

后台侧边栏（数据统计 / 用户管理 / 分类管理 / 题库管理）**任何一项都不高亮**，看不出当前在哪个页面。

### 根因

`AdminLayout.vue` 的高亮 key 算错了：

```ts
// 修复前
const activeKey = computed(() => '/' + route.path.split('/')[2])
// 对 /admin/categories → split = ['', 'admin', 'categories'] → [2] = 'categories'
// 得到 '/categories'，而菜单 key 是 '/admin/categories'
// → value 与任何 option.key 都不相等 → naive-ui 的 --selected 类从不挂上
```

即**不是缺样式，而是选中态从未被激活**。

### 修复

```ts
// 修复后：拼回完整两段路径，question-edit 子路由归入「题库管理」
const activeKey = computed(() => {
  const segment = route.path.split('/')[2] ?? ''
  if (segment === 'question-edit') return '/admin/questions'
  return segment ? `/admin/${segment}` : '/admin/dashboard'
})
```

同时补强选中态视觉（使用项目设计变量，与前台 `Emerald` 体系一致）：

| 状态 | 表现 |
| --- | --- |
| 选中项 | 浅品牌底 `--brand-50` (#e7f8f1) + 文字 `--brand-700` (#067a5b) + `font-weight: 600` + 左侧 3px `--brand-500` 强调条 |
| 悬停未选中项 | `--bg-soft` 浅灰底 |
| 悬停已选中项 | **与选中态完全一致（不变色）** |

顺带把该组件里硬编码的 naive 默认绿 `#18a058`（logo 方块、logo 文字、头部头像）统一为品牌变量 `--grad-brand` / `--brand-700` / `--brand-500`，消除与前台的色差。

### 踩坑：选中态不能改 `::before`，要改 `theme-overrides`（重要）

第一版把选中色写在 `.n-menu-item-content--selected::before` 上（涂成 `--brand-500` 深绿并改成 3px 宽），结果出现**「鼠标一悬停，深绿瞬间变浅绿」**的跳变。原因有两层：

1. **`.n-menu-item-content::before` 并不是左边条，而是 naive-ui 用来绘制「选中背景胶囊」的载体**（`position:absolute; left:8px; right:8px; top:0; bottom:0`，带 `background-color .3s` 过渡）。把它改成 3px 深绿竖条，等于劫持了选中背景。
2. 悬停时 naive 自己的 `.n-menu-item-content--selected:hover::before` 规则会接管，把背景换成 `--n-item-color-active-hover`。实测正是这一条导致 `rgb(16,185,129)` → `rgba(16,185,129,0.1)` 的 0.3s 渐变。

**更关键的坑**：想用 CSS 覆盖这些主题变量是**无效的** ——

```
document.querySelector('.n-menu').getAttribute('style')
// → --n-item-color-active: rgba(16, 185, 129, 0.1); --n-item-text-color-active: #10B981; ...
```

naive-ui 把 `--n-*` **以行内样式写在组件根元素上**（`document.styleSheets` 里搜不到任何包含这些变量的规则），行内样式优先级高于任何选择器（除 `!important`），所以 `.admin-layout :deep(.n-menu) { --n-item-color-active: ... }` 完全不生效。

**正确做法**：用组件自带的 `theme-overrides` 属性注入（值可以直接写 `var(--brand-50)`，仍以项目 token 为唯一来源）：

```vue
<n-menu :theme-overrides="menuThemeOverrides" ... />
```
```ts
// MenuThemeOverrides 未从 naive-ui 根导出，需走子路径
import type { MenuThemeOverrides } from 'naive-ui/es/menu/styles'

const menuThemeOverrides: MenuThemeOverrides = {
  itemColorHover: 'var(--bg-soft)',
  itemColorActive: 'var(--brand-50)',
  itemColorActiveHover: 'var(--brand-50)',      // 与 active 同色 → 悬停不再跳变
  itemColorActiveCollapsed: 'var(--brand-50)',
  itemTextColorActive: 'var(--brand-700)',      // naive 默认是 #10B981，在浅绿底上对比度仅 ~2.2:1
  itemTextColorActiveHover: 'var(--brand-700)',
  itemIconColorActive: 'var(--brand-500)',
  itemIconColorActiveHover: 'var(--brand-500)'
}
```

左侧强调条改用 **`::after`**（naive-ui 菜单未占用该伪元素），并在折叠态隐藏：

```css
.admin-layout :deep(.n-menu-item-content--selected::after) { /* 3px × 18px 品牌绿竖条 */ }
.admin-layout :deep(.n-menu--collapsed .n-menu-item-content--selected::after) { display: none; }
```
